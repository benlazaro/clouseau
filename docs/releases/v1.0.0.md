Title: Clouseau 1.0 — A fast desktop log viewer, ready for everyday use

## Clouseau 1.0

Clouseau is a desktop log viewer for software engineers and the people who support their
software: open a log of any size, find what went wrong, follow it across services, and hand
your findings to a colleague. After a long run of alphas and a release candidate, it's ready for
everyday use.

What 1.0 promises:

- **It installs cleanly.** Unzip and run on Windows, macOS or Linux; each zip brings its own
  Java. The [Installing](https://benlazaro.github.io/clouseau/guide/installing.html) page
  shows how to get past the warning Windows and macOS give an unsigned app the first time.
- **Upgrades keep your data.** Settings, sessions, parsers, auto-highlights, saved
  connections and notes carry over from one version to the next. A damaged file is set
  aside, never saved over.
- **The files Clouseau writes stay readable.** Sessions, notes and review bundles made by
  1.0 will open in every later version.

From now on, releases without a suffix (1.0.1, 1.1.0) are the stable ones. Release
candidates (`-rc`) come first, for anyone who wants to try what's next.

### What Clouseau does
- **Big files are fine.** Every file is indexed on disk rather than loaded into memory, so a
  million-line, 125 MB log opens in under 50 MB, and level, logger and time filters answer
  in milliseconds.
- **Reads your formats.** Log4j patterns, Spring Boot, JSON Lines (Logback, ECS, Serilog,
  pino, zap and more) and syslog are recognized by themselves. Add your own in the parser
  editor, without code. A file nothing recognizes opens as plain text.
- **One timeline across services.** Open several logs as one view, interleaved by time, even
  in different formats and timezones, and shift a file whose clock is off.
- **Find what went wrong.** Filter by level, logger, field, time range and text together;
  search every column; color rows by hand or with auto-highlights, and jump between them.
- **The detail panel reads the entry for you.** Stack traces with your own frames standing
  out, JSON and logged objects laid out, and a click on a frame opens the code in IntelliJ
  IDEA, VS Code or Cursor.
- **Live logs, local or remote.** Follow a file like `tail -f`, a server's log over SSH, or
  lines sent to a TCP or UDP port, without losing lines when a log rotates.
- **Findings you can hand over.** Note lines as you go; the notes are kept next to the log.
  **File → Export for Review…** packs the log and your notes into one file a colleague opens
  like any log.
- **Picks up where you left off.** Your windows, tabs and filters come back the next time
  Clouseau starts, and named sessions keep one set of logs per project.
- **Yours to arrange.** Several windows across monitors, columns and saved layouts, Dark
  and Light themes or any FlatLaf theme, and plugins for more formats and log sources.

The [User Guide](https://benlazaro.github.io/clouseau/guide/) covers all of it.

### Plugins
- The plugin API keeps its own version number (0.3.0) and may still change before its own
  1.0; each API release says what changed. Plugins built for 0.17 and later keep working.

### Upgrading
- Close Clouseau before you start the new version.
- **Windows, from 0.18 or earlier:** those versions kept your data in the `data` folder next
  to `Clouseau.exe`. Before you delete the old `Clouseau` folder, either copy that folder's
  contents to `C:\Users\<you>\.clouseau`, or move the `data` folder next to the new
  `Clouseau.exe` to keep using Clouseau portable. From 1.0.0-rc.1 on, Windows keeps your
  data in your home folder, so this is needed only once.
- **macOS and Linux:** your data is in `~/.clouseau/`, outside the app, so replace the old
  app with the new one.
- A new download is a new app to your system, so you may have to allow it once more. See
  [Installing](https://benlazaro.github.io/clouseau/guide/installing.html).
