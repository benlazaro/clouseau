Title: Clouseau 0.17.0-alpha — Jump to the code, auto-highlights

## Jump from a stack trace to the code, and highlights that color themselves

### Jump to the code
- **Stack frames are links.** In the detail pane, each frame that names its file and line, such as **OrderService.java:42** in `at com.acme.OrderService.place(OrderService.java:42)`, is underlined. Click it and your IDE opens the file at that line. Right-click it for **Open OrderService.java:42 in IDE**. When an entry's logger is named after its class, the right-click menus of the table and the detail pane offer **Open "OrderService" in IDE** too.
- **IntelliJ IDEA (or any JetBrains IDE), VS Code or Cursor.** Choose one in **Settings → Source Code**. IntelliJ 2026.2 and later need JetBrains' free **IDE Remote Control** plugin; Clouseau tells you if it's missing.
- **Nothing to set up for the usual project folders.** Clouseau finds the file in `~/git`, `~/src`, `~/repos`, `~/IdeaProjects` and similar folders, in every project and module, and in the projects open in your IDE. To search somewhere else, add the folders in **Settings → Source Code**.
- **Opens in the right project.** If the file's project isn't open in your JetBrains IDE, Clouseau says which project to open first, since the IDE can't navigate a file outside an open project. **Open File Anyway** opens it regardless and brings the IDE to the front.
- **Says when it can't.** Frames from the JDK or a library aren't in your projects, so they can't be opened. A short note says so, for example "Can't open Thread.java because it's not in your projects".
- Java, Kotlin, Scala, Groovy and Clojure stack frames are recognized.

### Auto-highlights
- **Color every row that matches, in every log.** **Tools → Auto-Highlights…** keeps a list of things you always want to spot: `OutOfMemoryError` in red, a service's logger in blue, timeout warnings in amber. Each looks for text in any column or one column (message, logger, thread or a field), with match case, regex and a lowest level.
- **Live rows too.** Rows that arrive while you follow a log are colored as they come in, and rows change color as you edit the list.
- **Order matters.** The first auto-highlight that matches a row gives it its color. Right-click one, or press `Alt+↑` and `Alt+↓`, to move it.
- **Step through them.** Auto-highlighted rows appear in the **Highlights** bar like your own, so ▲ and ▼ step through them. Your own highlight on a row always wins.
- **Start one from a search.** In the find bar, **Highlight ⌄ → New Auto-Highlight…** starts one from what you searched for.
- Auto-highlights are your own setting: they aren't saved with a log's notes or put in review bundles.

### Find
- **The find bars keep still.** The ▲ ▼ arrows are greyed out when there's nothing to step through, instead of disappearing, so the match count stays in place.
- **Highlight ⌄ sits right after the search field** in the table's find bar, then the arrows and the count, as in the detail pane's find strip.
- **The detail pane's find strip waits for an entry.** It hides while no entry is shown (after clearing the filters, say) and comes back, with its search, on the next one.

### Look and feel
- **Tooltips stand out.** In the Dark theme they have their own lighter background and a visible edge, so they no longer disappear over the table header. Light tooltips get a stronger edge.
- **Confirmations default to Cancel when something would be lost.** Pressing `Enter` never deletes, clears or overwrites anything. The button says what it does (**Delete**, **Clear**, **Replace**, **Forget**) instead of **Yes** or **OK**.
- Short notes over the table and the detail pane stay up longer when they have more to say.

### Plugins
- The plugin API is unchanged (0.3.0). Plugins built for 0.16 keep working.

### Upgrading
- Close Clouseau before you start the new version. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions, parsers and saved connections), delete the rest, and unzip the new version in its place. On macOS and Linux your data is in `~/.clouseau/`, outside the app, so replace the old app with the new one.
