Title: Clouseau 1.0.0-rc.1 — The first release candidate for 1.0

## The first release candidate for Clouseau 1.0

This is the release we intend to ship as 1.0, unless you find a reason not to. Please try it
on your own logs, and [open an issue](https://github.com/benlazaro/clouseau/issues) for
anything that crashes, loses data or doesn't work as the guide says. If about two weeks go by
without a serious bug, it becomes 1.0.

What 1.0 promises:

- **It installs cleanly.** Unzip and run; each zip brings its own Java. The
  [Installing](https://benlazaro.github.io/clouseau/guide/installing.html) page shows how to
  get past the warning Windows and macOS give an unsigned app the first time.
- **Upgrades keep your data.** Settings, sessions, parsers, auto-highlights, saved
  connections and notes carry over from one version to the next.
- **The files Clouseau writes stay readable.** Sessions, notes and review bundles made by
  1.0 will open in every later version.

### Clearer stack traces and objects in the detail panel
- **Stack traces are colored.** The exception and each **Caused by** stand out, your own
  code's frames show their class and method in the accent color, and frames of the JDK,
  common frameworks and generated classes are dimmed. Every frame is still a link to the
  code. The **Stack Trace** button in the panel's header turns the coloring off.
- **Logged objects are laid out.** An object logged with its `toString()` (Lombok
  `@ToString`, Kotlin data classes, Java records, `Name{key=value}`, Apache's
  `ToStringBuilder`, maps and lists) is shown one field per line, indented by depth, with
  class names, keys and values in their own colors. Only whitespace changes. The
  **toString** button in the header shows it as it was logged.

### Your data is safer
- **Windows keeps your data in your home folder.** Settings, sessions, parsers and saved
  connections are now in `C:\Users\<you>\.clouseau`, as on macOS and Linux, so deleting the
  old `Clouseau` folder to upgrade no longer deletes them. To keep them with the app
  (portable), put a folder named `data` next to `Clouseau.exe`. **File → Settings… → Data
  Folder** shows which folder is in use.
- **A damaged file no longer stops Clouseau or gets overwritten.** If `settings.json` or
  `parsers.json` can't be read, it is set aside as a `.bad` file and Clouseau starts with
  the defaults, instead of failing to start or saving over it. Saves go through a temporary
  file, so a crash in the middle of one can't leave half a file.
- **Saved passwords stay encrypted.** If the saved-password store can't be opened (for
  example, a portable data folder moved to another computer), Clouseau starts a new one and
  asks for those passwords again. Before, it could save new passwords unencrypted.

### Menus and keyboard
- **A simpler File menu.** **Open File…**, **Open via SSH…** and **Open TCP/UDP
  Listener…** are at the top, then any plugin sources, then your recent files, numbered,
  above **Exit**. **Browse Plugins** moved to **Tools → Plugins…**.
- **macOS shortcuts use Cmd.** Every shortcut is Cmd on a Mac, as the menus already were,
  except switching tabs with `Ctrl+Tab` and `Ctrl+PageDown` / `Ctrl+PageUp`. Tooltips and
  **Help → Keyboard Shortcuts** say Cmd too.

### Fixes
- **No more Clouseau left running without a window.** Starting a new version while an old
  one ran could hide the "already running" message behind other windows, so the new one sat
  waiting unseen. The message now opens in front with its own taskbar button. Quitting also
  can no longer leave a process behind if shutting down hangs.
- The **Add Repository** dialog in the Plugin Manager grows to show the username and
  password fields when you choose a sign-in method.
- Text in the detail panel's accent color is drawn bold, so it's easier to tell apart.
- Updated libraries with security fixes: sshj, Bouncy Castle, Log4j and PF4J.

### Plugins
- The plugin API is unchanged (0.3.0). Plugins built for 0.17 and 0.18 keep working. The API
  keeps its own version number and may still change before its own 1.0; each API release
  says what changed.

### Upgrading
- Close Clouseau before you start the new version.
- **Windows, from 0.18 or earlier:** those versions kept your data in the `data` folder next
  to `Clouseau.exe`. Before you delete the old `Clouseau` folder, either copy that folder's
  contents to `C:\Users\<you>\.clouseau`, or move the `data` folder next to the new
  `Clouseau.exe` to keep using Clouseau portable.
- **macOS and Linux:** your data is in `~/.clouseau/`, outside the app, so replace the old
  app with the new one.
- A new download is a new app to your system, so you may have to allow it once more. See
  [Installing](https://benlazaro.github.io/clouseau/guide/installing.html).
