Title: Clouseau 0.14.1-alpha — A clearer timezone popup, a quieter status bar

## A clearer timezone popup, a quieter status bar

### Timezones
- **The timezone popup says what each setting means.** *Written in* is the timezone the log's timestamps were written in; *Display* is the timezone every tab shows times in. *Same for all open tabs* sets every open tab to the same *Written in* timezone, and the note at the bottom says that changing *Written in* reloads the log.
- **A merged view whose files have different timezones says "Per file"** in the status bar instead of "Mixed".
- The popup has rounded corners on Windows 11, like Clouseau's menus and drop-down lists.

### Status bar
- **The status bar's text is gray**, so it no longer competes with the log above it.
- **The timezone lights up when you point at it**, to show it opens the timezone popup. A thin line separates it from the row counts.

### Detail pane
- **Right-click to copy.** The detail pane's Copy button is gone. Its right-click menu has *Copy Message*, *Copy Raw Line* and *Copy Entry*, named as in the table's row menu and the Edit menu. *Copy* appears only when you've selected some text.

### Fixes
- **File → Recent Files** leaves out files that were deleted or moved since you opened them, and is greyed out when none are left. Before, it kept listing them until you opened another file.

### Upgrading
- Close Clouseau before you start the new version. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions, parsers and saved connections), delete the rest, and unzip the new version in its place. On macOS and Linux your data is in `~/.clouseau/`, outside the app, so replace the old app with the new one.
