Title: Clouseau 0.12.0-alpha — Saved SSH connections by folder, rename servers in place

## Saved SSH connections by folder, and servers you rename in place

### Remote logs
- **Saved connections are grouped by folder.** In the SSH dialog, Saved connections is now a tree: each server, the folders of its saved logs, then the logs. Server names are in bold. Click the arrow beside a server or folder (or double-click it) to fold it, and the dialog remembers what you folded. While you type in the filter box, every match shows.
- **Rename a server where it's listed.** Right-click a server and choose **Rename**, or select it and press F2. Type the name and press Enter (Esc cancels); clear it to show the host again. Two servers can't share a name. The form now shows the name under **Server** without letting you edit it there.
- **Right-click menus on saved connections.** Every row has one: **Rename** on a server, **Duplicate** on a log, and **Forget** on all three. A folder's trash can forgets every log in it, after asking when there's more than one.
- **Test moved next to the path it checks.** **Test** is now on the **Remote path** line, after **Browse…**, instead of in the dialog's footer, where it looked like it would test the server selected in the list.

### Upgrading
- **Starting a new version while an old one is still running.** Clouseau used to hand your files to whichever Clouseau was already running, so after an upgrade the old version could keep opening instead of the new one, even with no window left. Now it says which version is running and asks you to close it. Versions 0.11.2 and older can't say which version they are, so Clouseau tells you an older version is running.
- To install this version over an old one, close Clouseau first. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions and parsers), delete the rest, and unzip the new version in its place.
