Title: Clouseau 0.18.0-alpha — Receive logs over TCP/UDP, JSON Lines and Syslog

## Receive logs over the network, and read JSON Lines and Syslog

### Receive logs over TCP/UDP
- **Logs sent to Clouseau, not read from a file.** **File → Open Remote → TCP/UDP…** listens on a port while its tab is open and shows each line as it arrives, from any number of senders at once. It's useful for an app that logs to a socket or to syslog, a device on your desk, or a container.
- **TCP or UDP.** TCP takes one message per line, or syslog's length-prefixed frames. UDP takes one message per packet. The default port is 5140.
- **This computer only, unless you choose otherwise.** By default only programs on your own computer can send. Choose **Any computer on the network** to receive from a phone, a test rig or a virtual machine.
- **Text only.** Send plain lines, JSON Lines, syslog or any format you have a parser for. Clouseau never accepts Java's serialized log events, because reading them could let a sender run code on your computer. Use a JSON or syslog appender instead.
- **Works like your other live tabs.** If the port is already in use, the tab says so, with **Reconnect**. A received tab has the same connection dot as an SSH tab, and it reopens and listens again the next time Clouseau starts.

### JSON Lines and Syslog parsers
- **JSON Lines.** One JSON object per line, as written by Logback's and Log4j's JSON layouts, Elastic Common Schema, Serilog, pino, bunyan, zap, structlog, Python's JSON formatters and Docker's `json-file` driver. Clouseau finds the time, level, message, logger and thread under their usual names, and every other key becomes a column you can filter on. A stack trace in its own key is added to the message, so its frames link to your code.
- **Syslog.** Both the current format (RFC 5424) and the older BSD one (RFC 3164). The level comes from the priority, the app name is the logger, and **host** and **facility** are columns.
- Both are recognized by themselves, in files and in received logs.

### About and Licenses
- **Help → About Clouseau shows the plugin API version** under Clouseau's own, so you can tell which plugins will load.
- **Copy Details** in the About box copies both versions, with your Java and operating system versions, ready to paste into an issue. The "Clouseau ran into a problem" window's details now include the plugin API version too.
- **Licenses has one tab per license.** Clouseau, Apache 2.0, MIT, OFL 1.1, BSD 3-Clause and CC0. Each tab lists the libraries and fonts under that license, with their copyright and website, and then the license text.

### Keyboard
- **Every menu has an Alt shortcut.** `Alt+F`, `E`, `V`, `T` and `H` open the File, Edit, View, Tools and Help menus, and an underlined letter picks an item.

### Other changes
- A table cell shows the first line of a value that spans several lines.

### Plugins
- The plugin API is unchanged (0.3.0). Plugins built for 0.17 keep working.

### Upgrading
- Close Clouseau before you start the new version. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions, parsers and saved connections), delete the rest, and unzip the new version in its place. On macOS and Linux your data is in `~/.clouseau/`, outside the app, so replace the old app with the new one.
