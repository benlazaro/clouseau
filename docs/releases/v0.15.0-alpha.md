Title: Clouseau 0.15.0-alpha — Columns that fit, logs that keep their time, reloads that keep your view

## Columns that fit, logs that keep their time, and reloads that keep your view

### Columns
- **Double-click a column border to fit the column** to its title and the widest value in the rows in view. A click on a header border no longer sorts the column.
- **Fit columns to content**, in the header's right-click menu, fits every column but Message at once. Double-clicking Message's border does the same.
- **Message stays inside the window.** The columns always fill the window, and the detail pane shows a long message in full.

### Timezones
- **Timestamps that say their own offset keep it.** A time like `2026-03-27T08:00:00Z` or `+02:00`, as in JSON logs, already says when it happened. Before, setting a log's **Written in** timezone moved those times by hours. Now only times without an offset are read in that timezone.

### Reload File
- **Reload keeps your view.** Column widths, order and hidden columns stay as you had them, and so do hidden loggers, field filters and hidden files of a merged view. Levels, the time range and the text filter were already kept.

### Following and live sources
- **Follow tracks the newest line when you sort newest first.** With **#** or **Timestamp** sorted descending, Follow keeps the top in view. Before, it followed the oldest line, and new lines pushed the rows down even with Follow off.
- **A live source that fails to connect says why in the tab**, with a **Reconnect** button, instead of an error box over an empty table.
- The detail pane no longer jumps to the top each time a live tab gets new lines, and keeps your text selection. Row stripes stay with their rows when a live tab drops its oldest lines.

### Detail pane
- **Chinese, Japanese and Korean text shows properly** instead of as boxes.
- **Invisible control characters show as dim symbols** (`␀`, `␛`), so a log written as UTF-16 or with stray escape codes is readable. Copying still copies the original characters.
- **Syntax highlighting follows the theme**, in Dark, Light and custom themes, and every highlighter that applies to a message is used together.

### When something goes wrong
- **Unexpected errors are reported instead of lost.** If Clouseau hits an error it didn't expect, it keeps running and opens **Clouseau ran into a problem**, with the details and buttons to **Copy Details**, **Open Log Folder** and **Report Issue…** (which opens a new GitHub issue for you to paste them in; Clouseau sends nothing itself).

### Licenses
- **Help → About Clouseau → Licenses** shows Clouseau's license and those of the libraries and fonts it includes. The download also has them as files in a `legal` folder.

### Plugins
- This version has **plugin API 0.3.0**. Parsers, formatters and live sources built for earlier versions keep working.
- **Syntax highlighter plugins built for 0.14 or earlier need an update**: highlighters now name what each piece of text is (a key, a string, a number…) and the theme picks the color. The [plugin guide](https://benlazaro.github.io/clouseau/guide/developers.html#writing-a-plugin) shows how.

### Upgrading
- Close Clouseau before you start the new version. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions, parsers and saved connections), delete the rest, and unzip the new version in its place. On macOS and Linux your data is in `~/.clouseau/`, outside the app, so replace the old app with the new one.
