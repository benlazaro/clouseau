Title: Clouseau 0.14.0-alpha — Filter on several terms at once, windows named by their tab

## Filter on several terms at once, and windows you can tell apart

### Filtering
- **`&&` joins terms that must all match.** Type `request && id = 10 && value = 32` in the message filter to keep only messages that contain all three, in any order. Each term still works as before: case-insensitive, a regular expression when it is one, so `|` still means "or" inside a term. Hover over the filter box for a reminder.
- The filter searches the message text, not every column. The guide now says so.

### Windows
- **The title bar names the selected tab.** It shows the tab's name, then the named session you're in (if any), then Clouseau, for example `app.log — Payments — Clouseau`. With several windows open, you can tell them apart in the taskbar and in Alt+Tab. A window with no tabs is just "Clouseau".

### Documentation
- The guide's screenshots are retaken from the current version.

### Upgrading
- Close Clouseau before you start the new version. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions, parsers and saved connections), delete the rest, and unzip the new version in its place. On macOS and Linux your data is in `~/.clouseau/`, outside the app, so replace the old app with the new one.
