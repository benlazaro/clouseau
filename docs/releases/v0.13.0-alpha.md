Title: Clouseau 0.13.0-alpha — SSH connections you save once, a tidier row menu, easier-to-read themes

## SSH connections you save once, a tidier row menu, and themes that are easier to read

### Remote logs
- **A saved connection is one sign-in with its logs under it.** It holds the user, host, port and password or key, plus an optional name. Change a password once and every log on that connection uses the new one. Two accounts on the same machine are two connections. Clouseau converts your existing saved connections the first time you open the window.
- **Save without connecting.** **Save** (Ctrl+S) keeps a new connection, or your changes to a saved one, and the window stays open. If you leave a log with unsaved changes, Clouseau asks whether to save them.
- **Connect checks first.** It signs in and checks that the file is there before it closes the window. If a step fails, the window stays open, says which step failed, and saves nothing. The separate Test button is gone.
- **Adding logs is quicker.** **New** (Ctrl+N) is at the bottom left. Point at a connection or folder to see a new-log icon next to its trash can. On a folder, the icon starts a new log in that folder.
- **The list fits the sidebar.** Long names end in "…" and show in full in a tooltip, so the list never scrolls sideways. The window is now called **SSH Connections**.

### The log table
- **The right-click menu only holds actions on the rows you clicked.** Whole-tab actions moved to the menu bar: **Reload File** / **Reconnect** to File, and **Clear Table…** (now Ctrl+Shift+K), **Clear All Highlights…** and **All Notes…** to Edit.
- **Highlight colors are one row of swatches.** The row menu and the find bar's Highlight popup share it. Pick **None** to remove a highlight. Use Left and Right to move along the row. Each swatch has an edge in its own color, so the pale colors stay visible, and the ring that marks the current color now shows in the Light theme too.

### Open dialog
- **A star for favorites.** Click the star in the toolbar to add or remove the folder you're in. Favorites show each folder's name with its full path underneath. Right-click one for **Remove from Favorites** or **Copy Path**.
- **Column widths and order are kept** when you change folders. The file list is no longer striped in Dark.

### Parser Editor
- **Find parsers quickly.** A filter box sits above the list, the list has a draggable divider, and Clouseau remembers the window's size.
- **Problems show in the form.** Pressing OK with a mistake no longer opens a message box: Clouseau selects the parser, outlines the field and explains the problem in plain words below it.
- **Plainer actions.** **New Parser** and **Duplicate** are at the bottom left, and right-clicking a parser offers Duplicate, Move Up, Move Down and Delete…. The editor opens with nothing selected, and the hint explains when the order matters (Auto-detect: the first parser that matches wins).
- **Fixed:** the Parser Editor no longer crashes after you delete your only parser.

### Look and feel
- **Easier to read.** Field, button and toggle outlines are easier to see in both themes. Placeholder text is dimmer, so it doesn't look like something you typed.
- **Tooltips** appear sooner and stay up while the mouse is over them.
- **Rounded corners** on menus, list selections and drop-downs, to match the fields and buttons.
- **Dialogs are more consistent.** Esc and the close box act as Cancel. Clouseau remembers dialog sizes. Delete asks before removing anything. In Manage Sessions you can rename a session in place (F2).
- Plugin Open Source dialogs mark what's required and say what's still needed. The time offset, timezone and parser prompts for merged files are proper dialogs with Cancel and OK.

### Upgrading
- Close Clouseau before you start the new version. On Windows, keep the old `Clouseau` folder's `data` folder (your settings, sessions, parsers and saved connections), delete the rest, and unzip the new version in its place.
