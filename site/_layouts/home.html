Clouseau is a fast desktop log viewer. Open logs of any size, merge several services into one timeline, filter in milliseconds, and hand your notes to a colleague in one file.

Why Clouseau

Four things it's built to do well.

1M lines
< 50 MB

Big files are fine

A 125 MB log opens in under 50 MB of memory. Level, logger and time filters answer in milliseconds.

api.log:41 INFO POST /orders db.log:13 WARN slow query pay.log:88 ERROR 502

One timeline across services

Merge logs in different formats and timezones, and follow a request from one to the next.

→ review.zip

Findings you can hand over

Note lines as you investigate, then send the log and your notes to a colleague as one file.

Following · deploy@prod-01file rotated · no lines lost

Live logs, local or remote

Follow a file like tail -f, or a server's log over SSH, straight through log rotation.

Everything it does

Open anything

  • Any file size
  • Log4j, Spring Boot, JSON lines, syslog
  • .gz and .zip
  • Plain text fallback

Read and filter

  • Level, logger, field and time filters
  • Find across every column
  • Highlights you can jump between
  • Detail panel with pretty JSON
  • Jump to the code in your IDE

See the whole story

  • Merged views
  • Several windows
  • Named sessions
  • Columns and layouts

Share findings

  • Notes on any line
  • Review bundles

Watch it live

  • Follow mode
  • SSH
  • Receive over TCP or UDP

Make it yours

  • Dark and Light themes
  • Your own parsers, no code
  • Plugins, one click to install
